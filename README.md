## Healthcare Operations and Records Management

# Project Overview

This project demonstrates practical experience in healthcare administrative data entry, records management, data cleaning, and data quality control using Microsoft Excel.
The project uses a dataset of 200 fictional administrative records to simulate common data management tasks in a healthcare environment.


## Project Objectives
- Organize and maintain administrative records.
- Identify missing and duplicate information.
- Detect inconsistent data formats.
- Apply data cleaning techniques.
- Document identified errors and track their resolution.
- Prepare a quality check summary.

## Tools Used
Microsoft Excel

## Key Tasks Performed
- Entered and organized 200 administrative records.
- Reviewed records for missing values and duplicate references.
- Identified inconsistent name, state, and payment status formatting.
- Used Excel functions such as TRIM() and PROPER() to standardize text.
- Created an Error Log to document identified data quality issues.
- Developed a Quality Check Summary to provide an overview of the findings.
